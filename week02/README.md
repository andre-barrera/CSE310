# Overview

This project was done to analyze the video game sales data using Python. In this project I practiced data cleaning, grouping, aggregation, and visualization (using graphs).

The dataset used for this project contains information related to VideoGame sales obtained in "Kagle". It contains things like video game titles, genres, platforms, release years, and global sales. Dataset source: https://www.kaggle.com/datasets/gregorut/videogamesales?resource=download

The purpose of this project is to improve my data analysis skills and learn how to identify patterns using real world data sets
